# Instruções para agentes de IA

Lê este ficheiro, README.md e CONTRIBUTING.md antes de alterar o projeto. Instruções explícitas do utilizador têm prioridade.

## Projeto e colaboração

- React Native, Expo, TypeScript e npm, com package-lock.json.
- Tarefas partem de develop e seguem por PR para develop; entregas seguem por PR para main.
- Repositório público: nunca adicionar credenciais, tokens, ficheiros .env ou dados sensíveis; não introduzir serviços pagos sem pedido explícito.
- Preserva alterações existentes e mantém cada alteração focada.
- Acrescenta testes significativos para comportamentos alterados; não contornes testes nem enfraqueças proteções. Não faças push direto para develop ou main.
- Executa as verificações relevantes do README. Se algo não puder ser verificado, explica a limitação. A exportação Android não verifica compilação nativa nem iOS.
- Confirma branch, destino, diferenças e testes antes de criar PRs; não faças merge, publiques ou alteres configurações externas sem instrução apropriada.
- Mantém este ficheiro e CONTRIBUTING.md atualizados quando o processo mudar.
